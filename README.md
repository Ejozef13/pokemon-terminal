# Pokemon Terminal

Simple Linux terminal startup setup with Venusaur ASCII art and system info.

## Files
- `install.sh` - installs the setup
- `bashrc-pokemon.sh` - startup script
- `terminal-art/venusaur.txt` - Venusaur ASCII art

## Install
```bash
chmod +x install.sh
./install.sh
source ~/.bashrc

Save it.
